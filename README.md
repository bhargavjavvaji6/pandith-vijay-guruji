# Vikram Astrologer & Psychic — React + Bootstrap

## Requirements
- Node.js 18+ (Node 20+ recommended)
- VS Code or another editor

## Run locally

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal, usually:
http://localhost:5173/

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `src/main.jsx` — complete React single-page application
- `src/styles.css` — custom dark/gold astrology theme
- `index.html` — entry page
- `package.json` — dependencies/scripts

The image URLs point to the reference site's publicly served assets. If you want to self-host the images, download them and place them in `public/assets/`, then change the constants in `src/main.jsx`.
